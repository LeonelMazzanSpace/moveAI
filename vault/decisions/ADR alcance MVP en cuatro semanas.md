# ADR alcance MVP en cuatro semanas

El MVP dura 4 semanas (12/10/2026–06/11/2026), con dos Full Stack, y prioriza el
circuito usuario → plan → pago → reserva → asistencia → seguimiento → renovación.
Cada semana cierra con una demo.

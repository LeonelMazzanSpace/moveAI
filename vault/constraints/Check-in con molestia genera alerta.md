# Check-in con molestia genera alerta

Una respuesta de check-in con molestia o cambio de objetivos crea una alerta de
intervención para el staff. Molestia: Contactar o Derivar a Rehab. Cambio de
objetivos: Contactar o Marcar gestionado.

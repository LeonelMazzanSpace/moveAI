# Emails bloqueados por IP nueva en Brevo

Después de reemplazar una instancia, Brevo rechaza la API key por venir de una IP
desconocida y dejan de salir confirmaciones, avisos y recuperaciones de contraseña.
Lo mismo pasa con una key desactivada por 90 días sin uso. Sin defensa hasta decidir
cómo manejar las IPs.

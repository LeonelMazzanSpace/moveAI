# AWS Elastic Beanstalk

Destino de despliegue de la API NestJS. Mantiene la configuración y las variables
sensibles fuera del código y puede escalar a varias instancias sin cambiar la
arquitectura, lo que tiene consecuencias para los jobs programados. La cantidad de
instancias y el autoscaling todavía no están definidos.
